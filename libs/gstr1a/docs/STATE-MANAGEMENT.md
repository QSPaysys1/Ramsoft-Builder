# State management

- **Workspace:** `Gstr1aWorkspaceStore` — RETSUM counts, cache key.
- **Section:** `Gstr1aSectionStoreBase` — hierarchy, aggregate, retsave signals.
- **B2BA draft:** `Gstr1aB2baDraftStore` — diff summaries + draft section payload.
- **Return period:** `Gstr1aReturnPeriodStore` delegates to `GstrReturnPeriodStore`.
